# Project Overview

## Setup

```bash
npm install
npm run dev
```

important: **AI was leveraged to generate part of the code**, as what I want to showcase is the architectural decisions and not the speed of writing code.

## Focus:

- Minimalism - in terms of code
  - Single purpose components
  - No global state
  - Query as the source of truth
  - One path to fetch data
- Flexible error handling
  - ErrorBoundary component
  - SearchResolution component
  - RetryResolution component
- Use of server-only functions
  - getPokemon function
  - getRandomPokemonName function
  - PokemonUrlSync component
  - Evolutions component
  - Profile component
- Leverage of Next.js / Vercel features
  - Cache components
  - Server-only functions
  - Error boundary


### Fetching logic

By making the random Pokemon fetch go the deliberate way, we minimize the places where we need to handle errors and where we fetch, and we minimize the code we need to maintain.

### Error handling 

Reusable ErrorBoundary component with a resolution that helps the user to resolve the error rather than just retrying or start over. 


## Things not focused on:

- Visual design - Current visual design is generated by an AI model, just easily curated to look nice.
- Error avoidance - Nice features like fuzzy search, form errors, etc.
- WCAG compliance
- Strict typing of the PokeAPI response. `getPokemon` intentionally returns
  the raw `any` from `response.json()` to keep the code minimal. A real
  implementation would type (or validate) the response shape.
